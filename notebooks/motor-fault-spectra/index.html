這頁在做什麼#

這一頁把八種常見的馬達與旋轉機械狀態，各自轉成一張頻譜。訊號是簡化的教學模型：每個狀態用幾個正弦波與噪聲組合，頻率與振幅都是設定值。真實機器還會有軸承幾何、轉速波動、共振與負載變化。這裡的頻譜是「讀圖練習」，不是診斷公式。

先看九張圖。每一張的 x 軸是 0–500 Hz，y 軸是振幅。標題是狀態名稱。

FS = 2000
DURATION = 1.2
T = np.arange(0, DURATION, 1 / FS)
F_ROT = 30.0
F_LINE = 60.0
F_BEARING = 123.5
F_MESH = 250.0
RNG = np.random.default_rng(42)

先把八種狀態造出來#

每個狀態都只看 1.2 秒。取樣率 2000 Hz，所以頻率上限是 1000 Hz；圖只畫到 500 Hz。Normal 是基準，其他八個是常見故障的簡化模型。

這些模型不模擬真實機器的完整物理。它們只把「某個故障會在哪個頻率留下峰值」單獨拉出來。這樣讀者可以先學會看圖，再去面對真實資料的複雜度。

In [2]:
def noise(scale=0.05):
    return scale * RNG.normal(size=T.size)

signals = {
    "Normal": 0.10 * np.sin(2 * np.pi * F_ROT * T) + noise(0.04),
    "Unbalance": 1.50 * np.sin(2 * np.pi * F_ROT * T) + noise(0.05),
    "Misalignment": (
        0.80 * np.sin(2 * np.pi * F_ROT * T)
        + 1.20 * np.sin(2 * np.pi * 2 * F_ROT * T)
        + noise(0.05)
    ),
    "Looseness": (
        sum((0.8 / n) * np.sin(2 * np.pi * n * F_ROT * T) for n in range(1, 6))
        + noise(0.08)
    ),
    "Bearing fault": (
        1.20 * np.sin(2 * np.pi * F_BEARING * T)
        + 0.35 * np.sin(2 * np.pi * 2 * F_BEARING * T)
        + noise(0.10)
    ),
    "Gear mesh": (
        0.80 * np.sin(2 * np.pi * F_MESH * T)
        * (1 + 0.5 * np.sin(2 * np.pi * F_ROT * T))
        + noise(0.06)
    ),
    "Rubbing": (
        0.60 * np.sin(2 * np.pi * 0.5 * F_ROT * T)
        + 0.80 * np.sin(2 * np.pi * F_ROT * T)
        + 0.50 * np.sin(2 * np.pi * 1.5 * F_ROT * T)
        + noise(0.05)
    ),
    "Electrical": (
        1.00 * np.sin(2 * np.pi * 2 * F_LINE * T)
        + 0.20 * np.sin(2 * np.pi * F_ROT * T)
        + noise(0.05)
    ),
    "Bent shaft": 1.30 * np.sin(2 * np.pi * F_ROT * T + np.pi / 4) + noise(0.05),
}

九張頻譜#

把每個狀態做 FFT，取單邊振幅頻譜。這裡用 Hann window 降低 leakage，振幅用 window 的總和歸一化，所以峰值高度大致可以互相比較。

In [3]:
def amplitude_spectrum(x, fs=FS):
    n = len(x)
    window = np.hanning(n)
    spectrum = np.fft.rfft(x * window)
    amplitude = 2 * np.abs(spectrum) / window.sum()
    frequency = np.fft.rfftfreq(n, 1 / fs)
    return frequency, amplitude


fig, axes = plt.subplots(3, 3, figsize=(12, 8), sharex=True, constrained_layout=True)

for ax, (name, sig) in zip(axes.flat, signals.items()):
    frequency, amplitude = amplitude_spectrum(sig)
    ax.plot(frequency, amplitude, color="#1f4e79", lw=1)
    ax.set_xlim(0, 500)
    ax.set_ylim(0, 1.6)
    ax.set_title(name, fontsize=10)

for ax in axes[-1, :]:
    ax.set_xlabel("frequency [Hz]")
for ax in axes[:, 0]:
    ax.set_ylabel("amplitude")

這張圖的解析度#

訊號長度 1.2 秒，頻率解析度是 $f_s/N = 2000/2400 \approx 0.83$ Hz。這代表兩個很接近的峰值，在圖上可能黏在一起。軸承特徵頻率 123.5 Hz 與 4 倍轉頻 120 Hz 只差 3.5 Hz，大約是 4 個 bin。這個長度下還分得開，但再短就未必。

怎麼讀這張圖#

先記住幾個參考頻率：

  • 1x：轉頻，這裡是 30 Hz。
  • 2x：兩倍轉頻，60 Hz。
  • 2× line：電源頻率的兩倍，這裡是 120 Hz。
  • 軸承：123.5 Hz，通常不是轉頻的整數倍。
  • 齒輪噛合：250 Hz，兩側可能出現轉頻間隔的 sideband。

同一個峰值可能有多種解釋。120 Hz 可以是 4x，也可以是 2× line。只靠一張頻譜無法區分，還需要轉速、電源頻率與感測器位置。

不對心：1x 與 2x 一起出現#

下圖把「不對心」的頻譜放大，標出 1x 與 2x。兩個峰值都存在，而且 2x 比 1x 高。這是徑向頻譜的典型教學例子；實際比例會受轉速、負載與感測器方向影響。

軸承與齒輪：高頻區的指紋#

軸承故障的特徵頻率由軸承幾何決定，通常不是轉頻的整數倍。這裡用 123.5 Hz 當代表，並加上 247 Hz 的二次諧波。真實軸承會出現撞擊重複頻率與共振帶，單看低頻頻譜不夠，通常還要做 envelope analysis。

齒輪噛合頻率是齒數乘上轉頻。這裡設 250 Hz，並用 30 Hz 的轉頻去調變，所以主峰兩側會出現 220 Hz 與 280 Hz 的 sideband。

實務上不能只看一張頻譜#

  • 轉速不是常數：負載與電源頻率會讓轉速漂移，峰值也跟著移動。變轉速下要用 order tracking。
  • 感測器位置會改變振幅。徑向與軸向看到的分量不同，同一個故障在兩個方向可能長得不一樣。
  • 共振會放大某些頻率：峰值高不代表故障嚴重，可能只是剛好接近結構共振。
  • 相位與軸向資訊。彎軸與不平衡在振幅頻譜上都可能是 1x，要靠相位或軸向差異區分。
  • 軸承需要包絡：軸承的撞擊重複頻率常被低頻成分蓋住，envelope analysis 比直接看頻譜有效。

小結#

  • 頻譜把時間域看不到的頻率成分攤開。1x、2x、分數諧波、軸承頻率、齒輪噛合，各自對應不同的物理來源。
  • 同一個峰值可能有多種解釋。120 Hz 可以是 4x，也可以是 2× line。
  • 振幅頻譜只給大小，不給相位。彎軸與不平衡需要更多資訊才能分開。
  • 真實診斷要把頻譜、時域、包絡、相位、趨勢與維修紀錄一起看。

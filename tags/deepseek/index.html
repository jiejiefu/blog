DeepSeek-V4.1-Flash：把 global KV 壓到 890 bytes/token，骨幹反而大了近一倍

TL;DR DeepSeek-V4.1-Flash 最值得看的是它把「每個 token 的 global KV」壓到 890 bytes——大約是上一代 V4-Flash 的 1/4、V1 的 1/437；benchmark 反而其次。 同時，它的 backbone 從 284B 長到 552B，將近一倍。 這不是單點技巧。它同時動了三層：CED 讓 decoder 的 global KV 直接從 encoder 最後一層投影出來，prefill 的 global 分支只跑一半的層；CSA2 讓相鄰層共用 main KV、indexer K 與 Top-K，但不共用 query；FP4 把 KV 從 FP8 再砍一半。部署時再用 SWA Bounded Replay 把短期窗口移出 SSD，persistent KV 降到 1/8。 代價寫在論文裡：SWA 重建是近似的、CSA2 的 sparse selection 可能選錯、1M prefill 仍然不便宜。這篇把那些「可以省」與「不能假設」的地方分開講。 ...

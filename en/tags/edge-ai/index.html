Designing a Semiconductor Equipment Edge AI Platform: From Sensor Data to Intelligent Decisions

TL;DR An Edge AI platform is an end-to-end engineering system: data ingestion, feature engineering, inference, monitoring, and human workflows must all hold together. The design uses five layers: React/MUI presentation, Flask APIs, analytics, edge execution, and SQLite/file persistence. A bounded deque batches recent samples (for example, 500 records or about five seconds) before feature extraction; it is a buffer, not a durable queue. PHM combines signal features (RMS, FFT), One-Class SVM, DTW, and PCA drift monitoring, with interpretation left to engineers. AI agents are controlled application clients: the backend enforces tool allowlists, authorization, validation, and audit logging, not the LLM prompt. Deployment starts as a Docker Compose edge monolith and should scale to decoupled workers only when measurements justify it. Bottom line: Reliability comes from traceable data, explicit failure behavior, and governed agents — not from a single model or framework. ...

Smart Fab Edge-AI: Predictive Maintenance and Autonomous Decision Agent System

TL;DR The architecture spans six layers, from sensors and streaming through PHM, edge agents, and MES/EAP safety integration. A 20-machine, 3-channel, 2 kHz example generates about 41.5 GB/day of raw data; managed fleet size and high-frequency stream scale are separate metrics. Detection uses a two-stage pipeline: Isolation Forest screening followed by Autoencoder assessment, with alert consolidation to reduce noise. RUL prediction (Weibull, LSTM/Transformer, domain features) feeds 30-day and 7-day maintenance planning; the reported figures are project-specific, not universal benchmarks. Models move through standardized packaging, shadow deployment, canary rollout (5% → 20% → 100%), monitoring, and rollback. Edge Agents, Industrial RAG, and MLOps connect evidence and workflows, but safety-critical control stays outside the LLM. Bottom line: Make each layer observable, verifiable, and recoverable before expanding autonomous decision-making. ...
